## The game
Mr. Cruz has $5 and a craving. Get him to the bodega without getting robbed on the way.

## States
- 'choose final score' (start): type number in "First to"
- 'play rock paper scissors': choose rock paper scissors to compete with computer
- 'win or lose' (end): if you win, you're very cool, else if you lose, you suck
